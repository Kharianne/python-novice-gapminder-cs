## Instalace Pythonu a JupyterLabu

Nejjednodušší je nainstalovat distribuci Anaconda. Dostanete v ní Python 3 i JupyterLab
najednou.

1. Stáhněte si instalátor Anaconda Distribution pro svůj systém ze stránky
   <https://www.anaconda.com/download>.
2. Spusťte ho a nechte výchozí nastavení.
3. Zkuste spustit JupyterLab podle návodu v části
   [Spuštění JupyterLabu](../episodes/01-run-quit.md#spusteni-jupyterlabu). Pokud se vám
   v prohlížeči otevře, je všechno připravené.

## Bez Anacondy

Pokud už máte Python 3 z <https://www.python.org>, stačí v příkazové řádce spustit:

```bash
python -m pip install jupyterlab
```

JupyterLab pak spustíte příkazem `jupyter lab`, stejně jako v lekci.
