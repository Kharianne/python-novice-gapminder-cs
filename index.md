Tahle lekce je pro lidi, kteří s programováním začínají nebo s ním mají jen málo zkušeností.
Naučíte se v ní spouštět Python v prostředí [JupyterLab][jupyterlab], ukládat hodnoty
do proměnných a pracovat se základními datovými typy, tedy s čísly a textem.

Lekce počítá s JupyterLabem, ale dá se projít i v jiném prostředí pro Python 3,
třeba ve Visual Studio Code nebo v Google Colabu.

:::::::::::::::::::::::::::::::::::::::::: prereq

## Co byste měli znát a mít

1. Víte, co jsou soubory a složky a co je pracovní adresář. Umíte spustit interpret
   (_interpreter_) Pythonu.

2. Než začnete, máte nainstalovaný Python 3 a JupyterLab.

Jak na to, najdete v [pokynech k instalaci](learners/setup.md).

## Odkud lekce pochází

[Plotting and Programming in Python][original] ze Software Carpentry.
Původní lekci připravili Allen Lee, Nathan Moore, Sourav Singh, Olav Vahtras (eds.)
a další autoři. Původní dílo je Copyright (c) [The Carpentries](https://carpentries.org/)
a je dostupné pod licencí [CC BY 4.0][cc-by-human].

Lekci přeložila a upravila Kateřina Volfová (2026). Kromě překladu je zkrácená na první
tři epizody a ukázky kódu mají české názvy a texty. Všechny změny jsou vypsané v souboru
README v repozitáři lekce. Nejde o oficiální materiál The Carpentries a The Carpentries
ho nijak neschvalují. Podrobnosti o licenci najdete na stránce [Licence](LICENSE.md).
